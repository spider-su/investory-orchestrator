# Docs

Focused supporting documents live here. `AGENTS.md` remains the canonical source for current
architecture, runtime behavior, database shape, API surface, and developer workflow.

Use this folder for:

- targeted design notes or compatibility reports
- migration or refactor notes tied to a specific change area
- documents that would add too much noise to `README.md`

Do not use this folder for:

- alternate project overviews
- duplicate architecture summaries
- tool-specific agent instructions
- roadmap planning that belongs in `ROADMAP.md`

Current documents:

- `AGENTS.md` – canonical architecture and workflow guide
- `ROADMAP.md` – current and future goals
